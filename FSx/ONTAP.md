# ONTAP

NetApp's enterprise storage operating system.

## FSx for NetApp ONTAP

AWS managed service running NetApp ONTAP.

**Key Features:**
- Multi-protocol: NFS, SMB, iSCSI
- Storage efficiency (deduplication, compression, thin provisioning)
- Snapshots and cloning
- SnapMirror replication
- Multi-AZ option

**Use Cases:**
- Migrate NetApp on-premises to AWS
- Enterprise apps requiring NetApp features
- Hybrid cloud storage
- Databases, VDI, file shares

**When to Use:**
- Already using NetApp on-premises
- Need advanced storage features (snapshots, cloning, replication)
- Multi-protocol requirements

**vs Other FSx:**
- More features than basic file systems
- Higher cost than FSx for Windows/Lustre
- Good for lift-and-shift NetApp workloads
