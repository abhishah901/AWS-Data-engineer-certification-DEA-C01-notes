# NetApp

Enterprise data storage and management company founded in 1992.

## What They Do
- Storage hardware (NAS, SAN)
- ONTAP storage OS
- Cloud data services
- Hybrid cloud solutions

## Relevance to AWS
**FSx for NetApp ONTAP** - AWS managed service running NetApp's ONTAP software

## Key Point
Major enterprise storage vendor. Organizations using NetApp on-premises can migrate to FSx for ONTAP on AWS with minimal changes.
