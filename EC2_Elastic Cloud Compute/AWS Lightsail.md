# AWS Lightsail

Simplified, low-cost VPS (Virtual Private Server) service for small-scale applications.

## Purpose
Easy way to launch simple workloads without AWS complexity.

## Features
- Fixed monthly pricing (predictable costs)
- Pre-configured blueprints (WordPress, LAMP, Node.js)
- Includes compute, storage, networking
- Managed databases, load balancers, CDN
- Simple web console

## Use Cases
- Websites, blogs (WordPress)
- Development/test environments
- Small business applications
- Learning AWS

## Pricing
Fixed bundles (e.g., $3.50/month for basic instance)
- Compute + storage + data transfer included

## vs EC2
| Feature | Lightsail | EC2 |
|---------|-----------|-----|
| Complexity | Simple | Complex |
| Pricing | Fixed monthly | Pay-as-you-go |
| Use case | Small apps | Enterprise |
| Features | Limited | Full AWS |

## Integration
Can connect to VPC, use Route 53, CloudFront, but more limited than full AWS.

**Use:** Small projects, simple deployments, predictable costs. Not for enterprise/complex architectures.
